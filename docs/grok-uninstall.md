# Uninstall

`lfg --json uninstall` is a non-mutating plan. Add `--yes` to remove only lfg-owned Grok surfaces. Use `--keep-config`, `--keep-overrides`, or `--purge-project-orchestrator` to control the narrow optional surfaces. Grok authentication, the Grok binary, downloads, and the `~/.grok` directory are never removed.
