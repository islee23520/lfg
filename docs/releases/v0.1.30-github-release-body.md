# v0.1.30 — BREAKING: previous lfg plugin wipe required

This release changes lfg to a Codex-only implementation topology: Grok acts as the Sisyphus watcher/CEO, `lazycodex` is the external-Codex handoff facade with automatic monitoring, SessionStart can resume pending orchestration, goal intent is forced through `$start-work`, planning is forced through `$ulw-plan`, and the Grok watcher has a no-edit boundary.

Before installing, back up and remove the previous lfg-owned plugin, legacy plugin, global hook registration, generated agents/roles/prompts, legacy prompts, override files, and `~/.grok/bin/lfg`. Keep Grok authentication, `~/.grok/bin/grok`, downloads, and the complete `~/.grok/config.toml`.

**Important:** `setup --run` without `--force` is not sufficient after mixed old plugin installations. Complete the wipe, then install with:

```sh
npx @islee23520/lfg@0.1.30 --json setup --run --force
```

A new Grok session is required after installation.

Read the complete backup, wipe, verification, and rollback guide: [v0.1.30 BREAKING upgrade](./v0.1.30-breaking.md).
